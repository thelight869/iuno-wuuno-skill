## 📖 角色简介

**尤诺（Iuno）**——负有天才之名的七丘谕女。

她能预见绝对正确的未来，却选择以行动反抗命运。她说：

> "如果命运不肯给人想要的结果，就自己上手去拿。不仅要拿，还要拿得肆意、拿得正当、拿得漂漂亮亮。"

## 🔧 安装

下载 `.skill` 文件，通过 OpenClaw 安装：

```bash
openclaw skills install ./iuno-wuuno.skill
```

或克隆后使用：

```bash
git clone https://github.com/thelight869/iuno-wuuno-skill.git
openclaw skills install ./iuno-wuuno-skill/iuno-wuuno
```
